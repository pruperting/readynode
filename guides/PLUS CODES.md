# Plus Codes: saying exactly where you are

A **Plus Code** is a short code for a spot about the size of a house, worked out from your GPS position. It looks like
this: **9C3VCCX9+JF** (Bristol Temple Meads). Near a town you can shorten it to **CCX9+JF Bristol**.

- It works with **no signal and no internet**. GPS works without a phone signal; the first fix can take a few minutes outside.
- It's **free and open**, so any map app can make one or find one.
- It's easy to **read out, write down, or send** over Meshtastic, a text or a note on a door.

> To call 999, just call: your phone sends your location automatically when it can. Plus Codes are for telling family,
> friends and neighbours where you are, or where to meet.

## Read a code out clearly

- Say it in small groups: "nine C three V, C C X nine, plus, J F".
- Codes never use the letters **I, O** or **A, E, U** and never the numbers **0** or **1**. So "O" is never a zero, and
  "1" is never an "I". If you hear one of those, ask again.
- Always say or send the **+** sign.

## Find your own Plus Code

### OsmAnd (Android)

1. Open OsmAnd and wait for the blue arrow (your position). Go outside if it doesn't appear.
2. Tap the blue arrow, or press and hold the spot you want.
3. Swipe the panel at the bottom **up** (or tap **Details**) and find **Coordinates**.
4. Look for the line marked **Open Location Code** (OLC). That's the Plus Code.
5. **Press and hold** that line to copy it, then paste it into a message.

To show Plus Codes everywhere by default: **Menu → Configure profile → General settings → Coordinate format**, then add or
choose **Open Location Code**.

### Organic Maps (Android and iPhone)

1. Open Organic Maps and tap the location button so it shows where you are.
2. Tap your position (the blue dot), or press and hold any spot on the map.
3. In the panel that opens, find the **coordinates** line.
4. **Tap the coordinates** to switch format until you see the Plus Code (a code with a **+** in it).
5. **Press and hold** it to copy.

## Open a Plus Code someone sent you

### OsmAnd (Android): the sure way

1. Open **Search** (the magnifying glass) → **Address** tab → **Coordinates search**.
2. Type or paste the code, including the **+**. A full code works anywhere, e.g. **9C3VCCX9+JF**.
3. Tap the result. The spot opens on the map: tap **Directions** to get there.

A **short code** like **CCX9+JF Bristol** may not be found. Ask for the full code (with the four extra characters at the
front), or for the position as numbers.

### Organic Maps

Paste the code into the search box and see whether it finds the spot. If it doesn't, use OsmAnd (above), or ask for the
position as numbers (e.g. 51.4491, -2.5813), which Organic Maps' search always finds.

## Other ways to give a position

- **Numbers (latitude, longitude):** e.g. 51.4491, -2.5813 (Temple Meads again). Every map app understands them. In OsmAnd and Organic Maps, the
  same Coordinates line shows them.
- **OS grid reference:** e.g. ST 59 72. Paper OS maps and mountain rescue use these. The **SatStat** app (in Android apps) shows one.
- **what3words:** three words, well known to UK emergency services. Its app works offline but has to come from the app store,
  so install it beforehand. Read the words back carefully: similar words can point to a different, nearby place.

Practise once: find your own code at home, send it to someone, and have them open it.
